تطبيق صلاتي - مشروع Android Java بسيط متوافق مبدئيًا مع AIDE

طريقة الفتح:
1) فك ضغط الملف داخل الهاتف.
2) افتح AIDE ثم Open Project.
3) اختر مجلد Salaty_AIDE (المجلد الذي يحتوي settings.gradle و build.gradle).
4) انتظر مزامنة Gradle ثم اضغط Run/Build APK.

ملاحظات مهمة:
- المشروع يستخدم Java وواجهات Android الأصلية، ولا يحتاج AndroidX أو مكتبات خارجية.
- لا يوجد gradlew داخل المشروع؛ استخدم نظام البناء الموجود داخل AIDE.
- مواقيت الصلاة تُجلب من AlAdhan API عبر الإنترنت (طريقة الحساب 5)، وقد تحتاج مراجعة إعدادات الحساب والمدينة.
- عند فشل الإنترنت تبقى أوقات تجريبية ظاهرة؛ لا تعتمد عليها للصلاة.
- القرآن في هذه النسخة يعرض قائمة سور فقط ولا يحتوي النص الكامل. لم نضع نصًا غير موثوق.
- الأذكار المعروضة مجموعة أولية قصيرة وليست مكتبة أذكار كاملة.
- الأذان والتنبيهات والإشعارات، التفسير، الخط القابل للتغيير، واختيار GPS لم تُنفذ بعد.
- هذه نسخة تأسيسية قابلة للبناء والتطوير، وليست إصدارًا نهائيًا جاهزًا للنشر.
